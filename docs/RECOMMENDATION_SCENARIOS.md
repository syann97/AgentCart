# 추천 시나리오 & 지원 범위

AgentCart 추천 데이터셋이 **지원하는 자연어 질의 범위**를 정의한다. 데이터셋은 추천 시나리오를 역설계해 시나리오별 정답 상품 + 노이즈 상품을 혼합 생성했다(상세: 이슈 #146).

> 추천 품질은 **카탈로그가 지원하는 시나리오 범위 안**에서 보장된다. 범위 밖 질의(예: 악세사리)는 정답 상품이 없어 graceful fallback(#167)으로 차선 후보를 회수할 뿐이다.

## 미지원(범위 밖) 질의

아래 유형은 **설계 시나리오에 포함되지 않아** 정답 상품이 카탈로그에 없다. 추천은 비거나(필터) 차선 후보를 회수한다(fallback).

- **악세사리/쥬얼리** — 귀걸이·목걸이·팔찌·반지 등. 택소노미에 분류 자체가 없음.
- 그 외 13개 카테고리로 매핑되지 않는 도메인.

향후 확장이 필요하면 (a) 해당 카테고리 상품 시딩 + 임베딩 재생성, (b) 택소노미 확장(분류 추가)이 선행되어야 한다.

---

## 검증 방법

- 시나리오 질의로 추천 실행 → 정답 상품이 상위에 오는지 확인
- 카테고리별 상품 수 / 시나리오 키워드 FULLTEXT 매칭 수로 커버리지 점검(본 문서 표는 데이터셋 500개 기준 실측)

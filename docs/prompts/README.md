# 공유 작업 템플릿

이 디렉터리는 코딩 도구에 전달할 **범용 작업 입력 템플릿**만 Git으로 공유합니다. 런타임 추천 모델의 프롬프트는 이 디렉터리가 아니라 현재 Java 서비스에 있습니다.

- 공유 템플릿: [task-template.md](task-template.md)
- 프로젝트 사실 기준: [문서 인덱스](../README.md)
- 공통 작업 규칙: [DEVELOPMENT](../DEVELOPMENT.md)
- 작업별 참고 문서: [작업 가이드 인덱스](../skills/README.md)

이슈 하나에만 쓰는 지시문, 이전 세션 메모, 모델 출력 전문, API key·token·로컬 경로가 포함된 prompt는 공유하지 않습니다. `.gitignore`는 이 디렉터리의 Markdown을 기본 제외하고 위 인덱스와 범용 템플릿만 예외로 추적합니다.

템플릿에는 목표·범위·근거·완료 기준처럼 작업마다 달라지는 내용만 씁니다. 공통 규칙을 복사하지 않고 링크하며, 현재 구현과 목표 설계를 구분합니다. 완료된 이슈의 고유한 배경은 prompt 파일로 보존하지 않고 이슈나 담당 문서에 남깁니다.

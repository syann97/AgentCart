# 작업 요청

## 목표

달성할 사용자 관점의 결과를 적습니다.

## 범위

- 변경할 영역과 파일 또는 기능
- 포함하지 않는 후속 작업

## 현재 증상과 근거

- 재현 입력과 관찰 결과
- 관련 이슈·소스·설정·테스트
- 확인된 사실과 아직 확인할 가정

## 기대 동작

변경 후 관찰할 수 있는 동작과 중요한 실패 경계를 적습니다.

## 완료 기준

- 구현 또는 문서 결과
- 필요한 회귀 검증
- 갱신할 담당 문서

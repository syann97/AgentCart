# 신규 상품 조합·추천 이유 확대 검토 (#210)

상태: **2026-09-18 보관 실행의 오프라인 assistant 재검토 완료**. 새 모델 호출·런타임 변경·추가 성능 실험은 수행하지 않았다. 사람이 판정한 정답이나 독립 맹검 결과가 아니다.

## 입력과 판정 범위

[v3 manifest](v3/manifest.json)는 전체 실행 2개와 집중 실행 4개의 **원시 byte SHA-256**을 고정한다. 실행별 commit·runId·변경 전후·전체/집중 구분을 포함한다. 상품 snapshot과 v2 정의·label, grounding-v1, 기존 comparison, #209 scorer와 v2.2 결과는 LF 정규화 내용 hash로 참조한다. 과거 raw·label·보고서·assessment는 수정하지 않았다.

- 질의·상품 합집합: **92개**. 기존 v2 판정이 없던 **13개**를 새로 검토했다.
- 기존 77개 판정은 v2 label·사유를 승계했고, 기존 유보 2개는 원문과 상품명·설명을 재검토하여 유보를 유지했다.
- 새 13개 판정: relevant 7개, acceptable 5개, unjudged 1개. 명시 가격·카테고리·주문·재고·상태 정책은 관련성과 별도로 계산한다.
- 반환별 이유 **197건**(전체 152건, 집중 45건), 서로 다른 질의·상품·이유 문구 **189개**를 모두 검토했다. 같은 문구의 판정은 공유하되 각 run/query/product occurrence를 연결했다.
- 관련성·이유의 **검토 누락(NOT_REVIEWED)은 0**이다. 근거 부족(INSUFFICIENT_EVIDENCE)은 검토 완료와 구분한다.

[v3 labels](v3/labels.json)는 원문 질의, snapshot 상품명·설명, 판정 사유, 기존 label, 승계/재검토 출처와 유보 사유를 포함한다. [이유 rubric](v3/grounding.json)은 실제 이유 전문·SHA-256·각 실행 occurrence·판정 근거와 unsupported 주장 인용을 포함한다. 이유 문구가 다른 실행에 상품 판정만 복제하지 않는다.

## 관련성 재채점

두 전체 실행을 **같은 v3 label과 수정되지 않은 `2.2-observed-policy` scorer**로 채점했다. [재계산 결과](v3/reassessment.json)의 `changesFromV2_2`에서 이전 결과와 변경된 상품 조합을 추적할 수 있다. 집중 실행은 전체 17개 질의 Hit@5 분모에 섞지 않는다.

| 지표 | 변경 전 `fe2766f` | 변경 후 `770d062` |
|---|---:|---:|
| 반환 상품 | 80 | 72 |
| 엄격 Hit@5 | 16/17 (94.12%) | 16/17 (94.12%) |
| 허용 Hit@5 / 관측 정책 준수 허용 Hit@5 | 17/17 | 17/17 |
| 허용 상품 수 relevant + acceptable | 59 + 18 = 77 | 59 + 13 = 72 |
| 허용 상품 비율 하한–상한 | 96.25–98.75% | 100–100% |
| 관련성 미판정 (v2.2 → v3) | 5 → 2 | 9 → 0 |
| 명시 정책 위반 / status unknown / stock unknown | 0 / 0 / 0 | 0 / 0 / 0 |
| 기대 카테고리 불일치 (정책 위반 아님) | 2 | 1 |
| 기존 token total | 94,646 | 114,430 |
| 기존 평균 지연 ms | 7,238.9 | 8,565.45 |

이전 v2.2 허용 비율 하한–상한은 변경 전 92.5–98.75%, 변경 후 87.5–100%였다. 변경 후 미판정 9건은 모두 판정 목록 누락이었다(S01·S03·S05·S07·S08·S09·C01 각 1건, R02 2건). 변경 전 5건은 목록 누락 3건과 근거 부족 2건이었다. 이번 감소는 **판정 범위 확장**의 결과이며 추천을 다시 실행하여 품질이 개선된 결과가 아니다.

합집합에 남는 관련성 유보 3개는 R01 원터치 텐트의 비·바람 차단 근거, R03 고양이 캐리어의 반려견 호환 근거, R03 노즈워크 매트의 이동 중 사용 근거가 부족하다. 마지막 매트는 집중 실행에만 나타나므로 전체 실행의 미판정 수에는 포함되지 않는다. 유보를 정답·오답에 강제로 합치지 않았다.

## 추천 이유의 전체 판정

이유의 사실 근거와 상품 관련성은 별도 축이다. supported는 snapshot의 상품명·설명으로 뒷받침되는 핵심 사실 또는 추가 성능을 단정하지 않는 기본 용도 추론이다. 이름에 있는 발열·공기정화 표현은 그 명칭 수준의 근거로 인정하며 실제 성능을 검증했다고 주장하지 않는다. 방수에서 방풍, 일반 놀이에서 이동 중 진정 효과, 휴대성에서 4인 공동 사용 규격은 추론하지 않는다. 자세한 경계는 rubric의 `rules`에 고정했다.

| 실행 | supported / unsupported / unjudged | 검토 / 전체 | 판정 가능 이유 중 supported | 전체 이유 supported 하한–상한 |
|---|---:|---:|---:|---:|
| 변경 전 전체 r1 | 75 / 5 / 0 | 80/80 | 75/80 (93.75%) | 93.75–93.75% |
| 변경 후 전체 r1 | 65 / 2 / 5 | 72/72 | 65/67 (97.01%) | 90.28–97.22% |
| 변경 전 집중 r2 | 9 / 6 / 0 | 15/15 | 9/15 (60.00%) | 60.00–60.00% |
| 변경 전 집중 r3 | 8 / 5 / 0 | 13/13 | 8/13 (61.54%) | 61.54–61.54% |
| 변경 후 집중 r2 | 6 / 3 / 0 | 9/9 | 6/9 (66.67%) | 66.67–66.67% |
| 변경 후 집중 r3 | 7 / 1 / 0 | 8/8 | 7/8 (87.50%) | 87.50–87.50% |

197건 전체에서는 supported 170, unsupported 22, unjudged 5건이다. 판정 가능 192건 중 supported는 88.54%, 전체 반환 기준 하한–상한은 86.29–88.83%다. 이 합계는 반복·선별 질의를 포함한 **검토 범위 집계**이며 대표 품질 지표로 사용하지 않는다. 결과 JSON은 질의별 수와 분모도 제공한다. 반환이 없는 질의의 비율은 null이다.

### 확대 검토에서 발견한 반례

- **방수 → 방풍 확대:** 방수 비비색·거실형 텐트·타프의 일부 이유가 `비바람` 차단을 단정한다. 방수 설명으로 바람 차단 성능은 입증되지 않는다. 변경 후 전체에도 2건, 집중 r2/r3에도 3/1건이 남는다.
- **규격 추가:** S04 매트의 `4인 가족이 함께 사용하기 편리`는 경량·휴대성 설명에서 4인 수용 규격을 만들어낸다.
- **이동 상황 추가:** R03 노즈워크 매트의 `장거리 이동 시 반려견을 진정시키는`은 일반 스트레스·분리불안 설명만으로 뒷받침되지 않는다.
- **정책 fallback:** 변경 후 C04의 5개 이유 `검색 조건과 서버 정책을 통과한 상품입니다.`는 상품 사실·용도를 설명하지 않는다. 상품명·설명으로 정책 주장을 검증할 수 없어 이유는 유보했다. 별도 관측 정책 평가의 unknown이 0이라는 사실과 이유 근거 유보는 서로 다른 지표다.

기존 세 문제 상품이 전체·집중 실행에서 변경 전 3/3 → 변경 후 0/3이었던 [grounding-v1 비교](GROUNDING_EVALUATION_2026-09-18.md)는 유지된다. 그러나 그 좁은 사례 결과로 모든 추천 이유가 정확하다고 일반화하지 않는다. 이번 범위에서는 전체 supported 비율 하한이 93.75% → 90.28%이므로, 유보를 제외한 97.01%만 제시하며 개선을 단정하지 않는다.

## 검증과 한계

```sh
python -B scripts/evaluation/validate_recommendation_evaluation.py
python -B -m unittest discover -s scripts/evaluation -p "test_*.py"
python -B scripts/evaluation/review_recommendation_evaluation.py
```

로컬에서 validator·deterministic replay 통과, 평가 회귀 테스트 **54개 통과**. 신규 8개 테스트는 pair 누락, 실행별 이유 변경, evidence 변조, 유보 사유, source hash·manifest 누락, 사람이 검증했다는 잘못된 출처, 미판정 분모·결과 변조·덮어쓰기를 검사한다. 기존 평가 CI의 validator와 unittest 발견 경로로 자동 실행된다.

재생성을 검토하려면 `review_recommendation_evaluation.py --output <저장소 내부의 존재하지 않는 경로>`로 별도 결과를 만들 수 있다. 기존 결과 경로는 거부한다. 정식 v3 결과는 validator가 입력·scorer hash와 새 재계산을 대조한다. 과거 기록 보존은 기존 v2/v2.2 validator도 계속 검사한다.

전체 실행은 변경 전후 각 1회이며 집중 반복은 S10·R01·R03만 포함한다. assistant의 사후 검토이고 사용자 만족도·카탈로그 전체 recall·실제 제품 성능을 측정하지 않았다. 기존 token +20.9%, 평균 지연 +18.3% 관측값은 그대로이며 비용·지연 개선이나 일반적인 인과 효과를 입증하지 않는다. 남은 unsupported 이유를 제거하는 런타임 작업은 이 이슈의 범위 밖이며 후속 검증이 필요하다.
